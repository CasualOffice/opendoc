Explore

See the engine work — live, not in screenshots.

Every card below boots the same Rust and WebAssembly editor that ships in production, pre-loaded to show one capability. Activate a card to run it; the document stays entirely in your browser.

To keep the page fast and within the editor's memory budget, only one live editor runs at a time. Activating a card tears down the previous one.

  • 01 · Tables

    Edit real tables

    Click into cells, move the caret across rows and columns, and format inside a laid-out table.

  • 02 · Tracked changes

    Suggest edits

    Boots in Suggesting mode — type or delete and every change is recorded as author-colored markup.

  • 03 · Comments

    Review & comment

    Opens the review sidebar — select text, add a comment, and resolve threads in the margin.

  • 04 · Find & replace

    Search the document

    Opens Find & replace — match across the model, step through hits, and replace one or all.

  • 05 · Formatting

    Rich text formatting

    Bold, italic, color, styles, and paragraph controls from the ribbon — applied to a real selection.

  • 06 · Export

    Write .docx back out

    Edit, then Save to serialize the model to a real, semantic .docx — download it and reopen in Word.

The demos run the WebAssembly editor. Open the full editor to load your own document, or read the fidelity matrix for exactly what each construct supports.
