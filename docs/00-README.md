# Documentation map

Start here when working in this repository. The numbered files are durable design and
evidence records, not a reading list or a set of independent work queues. Read the
few documents relevant to the change, then check the implementation and its tests
before making a current support claim.

## How the rest of `docs/` works

- **Work state:** `109` owns open work and its order. The `tracker/` folder
  separates completed history and generates pending and in-progress views from
  `109`. A batch plan such as `168` explains scope and sequencing; its status
  must agree with `109`. Put new work in `109`, not in another tracker.
- **Measurements:** `153` is generated by `opendoc-parity`; `168` has generated
  score and projection blocks. Change their inputs and regenerate them, rather
  than editing generated tables by hand.
- **Decisions and contracts:** `08` holds ADRs. The closest numbered design doc
  holds the detailed contract and implementation evidence for a subsystem.
- **Historical evidence:** `14`, `99`, `104`, `105`, and `106` are closed to new
  rows. Their dated observations explain earlier decisions; they are not current
  status reports. [Retired plans and research](tracker/completed/retired-documents.md)
  lists files removed after a current source replaced them, with their original
  text recoverable from Git.

Find a topic by filename or content with `rg --files docs` and `rg -n '<term>'
docs`. The file list itself is the complete inventory; this page deliberately
does not copy every filename into another manual index.

## Keep documentation small and truthful

Update the existing contract or design record when behavior changes. Add a new
numbered document only when the work needs a durable, independently reviewable
decision or design that does not fit an existing record. A routine fix needs a
backlog row, focused tests, and a short update to the affected contract; it does
not need a new plan, audit, and tracker. Retire a historical file only after
its open work has a current home, references have been redirected, and the
original revision is recorded in the retirement index.
